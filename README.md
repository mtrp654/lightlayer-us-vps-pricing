## Premium、Standard、Global 三条线路怎么选

判断依据很简单：看你用户在哪儿。

Premium 是优化线路，走 CN2、CMIN2 这类面向中国大陆的通道。洛杉矶和圣何塞的 Premium 套餐，国内三网延迟大致在 150–180ms，晚高峰波动较小。这是三个选项里唯一为国内访问做过专门优化的。

Standard 是标准线路，带宽比 Premium 大，价格一样。洛杉矶 1 核 1GB 的 Standard 版给到 50Mbps 不限流量，Premium 同价只有 20Mbps。代价是国内访问的路径没优化过，延迟介于两者之间。

Global 是国际线路，带宽最大、最便宜，走普通国际出口，国内访问可能绕路，延迟 200–300ms，晚高峰会有丢包。它的适用场景很明确：业务面向海外用户，或者你只是要一个境外 IP 跑点轻量任务，不在乎那 100 多毫秒。

一句话规则：用户在中国大陆，选 Premium；用户主要在海外，选 Global；两边都有又不想付两份钱，Standard 是折中。

## 洛杉矶还是圣何塞：$4 和 $4.90 的差别在哪

这是本文最值得花时间的一节，因为这两档差价不到一美元，实际体验差得不少。

洛杉矶的优势是门槛和灵活度。$4/月 能买到 Premium 优化线路的 1 核 1GB，而且内存、CPU、硬盘、IP 都能自己配，最高能配到 32 核 32GB。同一个 $4 价位上，你其实有六个选项：20Mbps 不限流量、30Mbps 1TB、50Mbps 不限、100Mbps 5TB、100Mbps 不限、200Mbps 5TB，区别只在线路和流量政策。

**这里有个很多人没注意的取舍**：同样是 $4/月，Premium 优化线路有两个版本，20Mbps 不限流量和 30Mbps 1TB 流量。前者适合流量不可预测的场景（代理、爬虫、长期在线的服务），后者带宽多出 50%，但一个月只有 1TB。1TB 摊到 30 天大约是每天 33GB，个人博客和小型 API 服务够用，跑下载或视频转发就不够。选之前先估一下自己的月流量。

圣何塞的定位不一样，它主打的是 1Gbps 端口。SJ-VP04-L 给到 1Gbps 带宽配 1TB 月流量，$9.90/月，比洛杉矶贵一倍多，换来的是突发下载能力和更大的端口上限。

$4.90 的 LITE 版看起来是圣何塞的便宜选项，实际上做了三处降级，而且这三处都写在配置表里，很容易只看到价格：

- 硬盘是 50GB HDD，不是 SSD。系统盘用机械盘，装系统、跑数据库、解压文件的体验完全是另一回事。
- 端口 300Mbps，不是 1Gbps。
- 月流量 500GB，不是 1TB。
- 另外它**仅支持 Linux**，装不了 Windows，可以额外买流量包，最高能升级到 2 核 2GB。

价格便宜一半，性能差距不止一半。LITE 适合 Linux 学习、开发测试、跑个低负载的小站；稍微正经一点的用途，加 5 美元上 SJ-VP04-L 更划算。

## 年付、续费与真实成本

年付是这家最容易踩坑也最容易省钱的地方。

省钱的部分：$24.99/年 的套餐覆盖台湾、香港、洛杉矶、新加坡、菲律宾等地，1 核 1GB / 50GB NVMe / 不限流量，折算每月两块出头。圣何塞曾出现 $10.9/年 的特价（1 核 1GB / 50GB / 1Gbps / 1TB），配合当时一个有效期到 2026 年 2 月底的六折码，能压到约 $6.5/年。这些码现在都已经过期，不要再按那个价格做预算。2026 年 1 月那一批促销也是如此：马尼拉 E3 独服五折、圣何塞 E5 独服 $57/月、阿什本 VPS $4.9/月，活动都在当年 1 月底结束。

需要留意的部分：

- **没有无理由退款**。官方条款的口径是只有商家责任范围内（机器故障、服务问题）才能申请退款或换机，常规价和促销品都不在无理由退款范围内。年付 VPS 在部分渠道的说明里明确写着不支持退款。这意味着年付相当于一次性付清，试错成本要自己承担。
- **年付能不能升级配置，来源之间有矛盾**。有资料说年付套餐配置都支持升级，也有资料说年付 VPS 不支持升级，圣何塞两款套餐页则明确写了支持升级。差异可能出在套餐类型上，但下单前必须问清楚你买的那一款属于哪种。
- **续费价格**：官方促销页宣称续费同价，不搞首年便宜、次年翻倍那套。这是促销页的说法，条款页面没有对应承诺，当作参考而不是保证。
- 优惠码一般只限首次购买使用，年付套餐码和促销款码不能叠加；促销独服不享受续费 9.5 折，但可以参与买 5 赠 1、买 10 赠 2。

按这个规则，比较稳的做法是先月付一台用两三周，确认线路在你所在地区的实际延迟和晚高峰表现，再决定要不要转年付锁价。$4 的月付成本换一个确定性，比直接付一年再发现问题划算。

## 已经能查到的实测数据

以下都是第三方测评和用户实测的记录，不是第一手测试，机型和测试时间不同，不能合并成单一结论。

2024 年 5 月针对洛杉矶优化线路、30M 带宽、4GB 内存机型的记录：CPU 是 AMD EPYC 7H12（64 核 128 线程，2.6GHz 主频，3.3GHz 加速），启用 BBR，**不支持 IPv6**，硬盘 I/O 约 225MB/s。路由上，去程电信和联通都是直连美国圣何塞节点后接 Cogent 到洛杉矶，移动直连洛杉矶；回程三网全部强制走移动 CMIN2 / AS58807。这个回程设计对移动用户友好，电信用户回程也走 CMIN2。

综合测评的延迟数据：优化线路国内三网 150–180ms，晚高峰比较稳；香港和台湾机房 30–50ms；国际线路国内 200–300ms，晚高峰有丢包。I/O 在 500–800MB/s。另一份促销期测评记录洛杉矶优化线路 I/O 500MB/s 以上、Geekbench 单核 600–700，延迟电信约 150ms、联通 160ms、移动 170ms，20Mbps 优化带宽在晚高峰能跑满，下载约 2.5MB/s。

香港机房的流媒体解锁能力，两份来源说法相反：一份说香港 IP 不是原生 IP，解锁 Netflix、Disney+ 可能受限；另一份说 Netflix 香港区和 Disney+ 都能正常访问。这个问题没有确定答案，如果你买它就是为了看流媒体，以下单页说明或自己实测为准，别把宣传当结论。

## 谁适合，谁不适合

适合的人：需要一台中国大陆访问延迟在 150ms 左右、月付几美元的美国 VPS 建站或做轻量服务；需要 1Gbps 端口跑突发下载；想用支付宝付款、不想折腾外币信用卡；能接受英文工单、几小时响应的节奏。

不适合的人，说清楚几点：

- 需要 7×24 中文客服的，这家主要用英文工单沟通，紧急问题可以走 Telegram，响应是几小时级别，不是分钟级。
- 需要 SLA 承诺的，官方没有明确的 SLA。生产环境要自己做好冗余。
- 要高并发生产环境的，1 核 1GB 那几档就是轻量用途，跑 WordPress 建议至少 2 核 2GB，跑数据库或高并发从 4 核 4GB 起。
- 要原生 IP 解锁流媒体的，前面说过香港的结论不确定，别把它当作稳定的解锁方案。
- 装 Windows 的，2GB 内存以上套餐才支持，且 LITE 版只支持 Linux。

几个购买前常问的细节：支付支持支付宝、PayPal、信用卡和加密货币（2024 年 5 月的资料还写着仅支持 PayPal，之后才陆续开放，以下单页实际选项为准）；VPS 付款后 5–10 分钟自动开通，独立服务器需要 12–24 小时人工部署；换 IP 首次免费一次，之后每次约 $2–5；基础 DDoS 防御免费给到 1–5Gbps，更高防护要付费；VPS 默认 1 个 IPv4，可付费追加到 20–32 个（视套餐）；不限流量套餐超量不会被限速，限量套餐超了会被限速或暂停，可以联系客服买流量包。
